### Экспериментальный бенчмаркинг методик приоритизации поведенческих групп

Для определения количественных ориентиров качества приоритизации на датасете RetailRocket воспроизведены адаптированные публично описанные методики Mixpanel Signal, Contentsquare Impact Evaluation и Fullstory Conversion Rate Impact.

Сравнение проведено на шести последовательных тестовых периодах продолжительностью семь дней. Для формирования рекомендаций использовались данные предшествующих 14 дней.

Получены следующие средние значения Benchmark:

- Hit@1 — 100%.
- Impact Capture@1 — 100%.
- Impact Capture@3 — 95,83%.
- NDCG@3 — 0,9728.

Высокие показатели качества могут объясняться следующими факторами:
- Ограниченное разнообразие поведенческих данных RetailRocket, представленных тремя типами событий: просмотр товара, добавление в корзину и покупка.
- Небольшое количество заранее определённых поведенческих групп, упрощающее задачу ранжирования.
- Устойчивость различий в конверсии групп между исследуемыми периодами.
- Концентрация 95,06% положительного Impact в одной поведенческой группе, существенно упрощающая выбор первой рекомендации.
Дополнительное сравнение с фиксированным историческим ранжированием показало, что в рассматриваемом сценарии простой контрольный подход также обеспечивает высокое качество приоритизации. Следовательно, высокие показатели сами по себе не доказывают преимущество более сложных методов.

Результаты являются экспериментальными ориентирами для выбранного датасета и сценария, а не оценкой точности оригинальных коммерческих продуктов.

При увеличении количества групп, автоматическом обнаружении новых групп, использовании более разнообразных поведенческих данных и изменении пользовательского поведения качество приоритизации может снизиться. Возможность обобщения результатов требует дополнительной экспериментальной проверки.
